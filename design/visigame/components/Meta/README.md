# Meta

The lens-metadata line: a row of short mono facts separated by dots, the way a camera writes `f/1.4 · 35 mm · ISO 800` at the edge of a frame.

- `items`: an array of strings or nodes, three or four at most.
- `tone`: default `ink-muted`; `tungsten` for the eyebrow above a hero or screen title; `peaking` for what is in focus right now.
- `as`: the element, `p` by default.

Use it above titles (eyebrow), under world names, in node headers and status bars. Items are facts, not prose: a genre, a biome, a seed, a count, a version. Written in capitals by the style; type them in sentence case in code.
