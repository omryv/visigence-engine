# Icons

The studio's line icon set, copied exactly from the product: 24 × 24 viewBox, stroke 1.5 (`stroke-icon`), round caps and joins, outline only. These files are single-ink, drawn in neutral `#8d9096` so they read on both themes in this gallery. In the product, use the `Icon` component or inline the paths so they inherit `currentColor` (`ink`, `ink-muted`, or a signal token).

| Name | Used for |
| --- | --- |
| theme | Themes in the asset library |
| mountain | Environments / world pools |
| enemy | Enemies |
| target | Objectives |
| folder | Doors, open project |
| cube | Props |
| crosshair | Weapons |
| settings | Configuration |
| download | Export project, download game |
| undo, redo | History |
| bolt | Generate & play (with `arrow` after the label) |
| arrow | Forward, continue |
| expand | Expand the preview |
| play, pause | Play state |
| close | Close play mode, dismiss |
